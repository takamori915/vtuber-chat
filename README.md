# AI VTuber Chat

AI（Claude）とチャット形式で会話でき、チャットの後ろの VTuber 風キャラクターが会話の内容に合わせて表情を変えて反応する Web アプリです。

## 特徴

- 7種類の表情（ふつう・嬉しい・悲しい・怒り・驚き・考え中・照れ）とエフェクト
- まばたき・呼吸・頭の揺れ・視線追従・口パク
- AI の返答に含まれる表情タグ（`[happy]` など）を読み取り、文章の流れに合わせて表情を切り替え
- 返答の読み上げ（端末の声、または VOICEVOX。VOICEVOX では声の大きさに合わせて口パク）
- キャラクター名・性格・口調、使用モデルを設定画面から変更可能
- 設定画面に「金髪のロングにして」のように書くと、AI が髪型・色・アクセサリーを決めて見た目を変更
- API キー未設定時はデモモード（簡易応答）で動作

## 使い方

1. GitHub Pages などで公開するか、ローカルで静的サーバーを起動します（例: `python3 -m http.server`）。
2. 右上の ⚙ から Anthropic API キーを入力して保存します。
3. チャット欄からメッセージを送信します。

## VOICEVOX で読み上げる

[VOICEVOX](https://voicevox.hiroshiba.jp/) を PC で起動しておくと、その声で読み上げられます（スマホ単体では使えません）。

1. PC に VOICEVOX をインストールして起動する
2. 初回だけ、ブラウザで `http://127.0.0.1:50021/setting` を開き、「許可するオリジン」にこのサイトのオリジン（例: `https://takamori915.github.io`）を追加して保存し、VOICEVOX を起動し直す
3. このアプリの ⚙ →「読み上げの声」で「VOICEVOX」を選び、「接続して声を読み込む」を押してキャラクターを選んで保存
4. 🔊 で読み上げをオンにする

VOICEVOX の音声を使っている間は、利用規約に従って画面右上に「VOICEVOX:キャラクター名」と表示します。
URL を変えれば、同じ API を持つ VOICEVOX エンジンをサーバーで動かしたものにも接続できます。

## キャラクターの仕組み

- 絵は `index.html` 内の SVG で描いており、目・口などの表情パーツを CSS で切り替えています。
- まばたき・頭の揺れ・視線・口パクは `app.js` が毎フレーム各パーツを動かしています。
- 見た目の変更では、AI が「髪型・髪色・瞳の色・服の色・猫耳の有無」などの値を JSON で返し、それを SVG の色やパーツの表示に反映します（絵そのものは描き直さないため、表情や動きはそのまま使えます）。

## 注意

API キーはブラウザの localStorage に保存され、ブラウザから Anthropic API に直接送信されます。
自分用の利用を想定しています。不特定多数に公開する場合は、キーを隠すための中継サーバーを用意してください。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面構成とキャラクター（SVG） |
| `style.css` | レイアウト・表情の切り替え・アニメーション |
| `app.js` | キャラクター制御、チャット、Claude API 連携、デモモード、読み上げ |
