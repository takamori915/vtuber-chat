設定

キーはこのブラウザの localStorage にのみ保存され、Anthropic API へ直接送信されます。空欄の場合はデモモード（簡易応答）で動作します。共有PCでは入力しないでください。

キャラクター

チャットで「着替えて」「未来の服にして」と頼んでも着替えます。

見た目（イラストのとき）

AIが髪型・色・アクセサリーを決めて、すぐに反映します（APIキーが必要です。1回あたりの料金はメッセージ1通と同程度）。

写真をキャラにする

写真をドラッグして、顔が枠の中に入るように調整してください。全身を入れたいときは「拡大」を左にして縮小してください。

写真はこの端末のブラウザの中だけで処理・保存され、AIや外部には送られません（初回だけ、切り抜き用のデータ約40MBをダウンロードするので Wi-Fi がおすすめです）。
